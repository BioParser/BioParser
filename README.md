# BioParser

## Running

### Requirements

- **Python** `== 3.13` (backend)
- **uv** (package management)

### Dependencies

Download/update using `uv sync`
- FastAPI (API framework for the REST API)
- Uvicorn (ASGI web server)

#### Dev
- mypy (type checker)
- ruff (linter and formatter)
