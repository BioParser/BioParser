# Definition of Done

A user story is done when all of the following hold.

- Code is high quality and refactored where needed
- Code is merged into `main` (PR + one approval)
- User story is deployed to the staging server
- Automated tests cover the change: unit tests plus tests derived from the user story and its acceptance criteria
- Acceptance criteria are met
- User documentation is updated if the change affects how the product is used
- Database, use-case, and other design docs are updated if they changed

Work is always merged to **`main`** through a pull request with **one review**. `main` stays production-ready.
