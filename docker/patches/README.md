# Image patches

Scripts in this folder rewrite installed packages after the image installs them. They are not imported by BioParser. The Dockerfile copies a script in and runs it in the same layer as the install. One script may rewrite more than one package. Each package is its own patch and its own row. A script must exit if the function text it rewrites is gone, so a package update fails the image build instead of shipping a silent no-op.

A version pin is not a patch. Pins stay on the `uv pip install` line in the Dockerfile.

| Patch | Reason | Upstream status | Check when updating the package |
| --- | --- | --- | --- |
| MinerU, in [mineru_glyph_edges.py](mineru_glyph_edges.py) | Native text puts a box on each character, then deletes that list before the line builder runs. Basic and above can rebuild the line text in Rust without copying the boxes. The patch still assigns each character to its span, copies the boxes before the delete, and the line builder keeps one glyph per character. A span with no character list contributes no glyphs. | Not upstream. Written against MinerU `4.2.3`. | `text/native.py` `fill_char_in_spans`, `chars_to_content` and the other `del span.metadata["chars"]`, and `text/content.py` `_build_ocr_det_line_items`, still match. `tests/parser/test_mineru_glyph_patch.py` fails the build path when that text moves. |
| DocVortex, in [mineru_glyph_edges.py](mineru_glyph_edges.py) | Native text clears each line's character list after measuring it, and postprocess later deletes `lines`. The patch copies each character's horizontal edges before that clear, keeps them when lines are merged, and copies the flat page's glyph lines into `extensions.bioparser_lines` once each block has its public index. Figure grouping then drops caption and footnote lines. A tagged page renumbers that snapshot with the same index map. | Not upstream. Written against DocVortex `0.6.24` only, the release the MinerU image installs. A different signature fails the image build. | `analyzers/native/pdf/pipeline.py` `_compact_prepared_lines` and `_normalize_output_line_items`, `line_merging.py` merged line construction, `postprocess/page_blocks.py` `_normalize_raw_blocks`, `postprocess/pdf_structure.py` `process_structure_blocks`, `postprocess/pages.py` `model_json_to_pages`, and `postprocess/document.py` `model_json_to_middle_json` still match, including `structure_extension`. A text layer parse fills glyph edges, including a figure caption. |
